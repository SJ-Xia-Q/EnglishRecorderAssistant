# 对抗性验收记录

验收目标不是证明顺利路径能运行，而是主动尝试缩短计时、误触操作、识别错误控件或破坏悬浮状态。

## 已自动验证

| 攻击/故障方式 | 必须守住的不变量 | 自动化结果 |
|---|---|---|
| 输入框、文本框或可编辑区域内按空格 | 不触发当前主操作 | 通过 |
| 焦点位于平台录音按钮时按空格 | 平台按钮保持原生键盘行为，助手不抢占 | 通过 |
| 长按空格产生 `repeat` 事件 | 不触发主操作 | 通过 |
| 倒计时期间连续按空格 | 不提前结束 5 秒或静音 | 通过 |
| 倒计时期间点击“重置/重新扫描” | 控件禁用，不能中断倒计时 | 通过 |
| 红词计时中阻塞主线程 2.2 秒 | 恢复后按绝对截止时间显示，不延长计时 | 通过 |

| 页面含隐藏重复剧本 | 只解析可见的真实剧本 | 通过 |
| 页面含同名“开始录音”诱饵按钮但没有时长 | 不悬浮诱饵，只接受同时含计时的真实控件 | 通过 |

| 任一轮缺少 `——Ns` | 明确停止在“无法识别”，不猜默认值 | 通过 |

| 1024×768 的 100%、125%、200% 等效 CSS 视口 | 两个悬浮控件均在视口内且不重叠 | 通过 |
| 权限与运行时代码静态检查 | 仅精确站点与 `storage`；无录音、网络请求或提前静音路径 | 通过 |
| 朗读空闲态持续观察 300ms | 面板不进行逐帧 DOM 重绘 | 通过 |
| 视觉截图检查朗读态和计时态 | 无无意义的 `0.0` 圆环；高缩放布局清晰且不重叠 | 通过 |

自动化夹具使用实际目标域名、浏览器扩展隔离环境和与页面截图一致的轮次/停顿格式。测试命令为 `npm test`、`npm run test:dom`、`npm run test:extension` 和 `npm run test:adversarial`。

## 必须在真实登录页面人工验证

自动化不能证明平台未来不会修改 DOM、按钮文字或权限流程。发布给其他录制人员前，需要在真实任务页逐项确认：

1. 点击“我已阅读并理解题目要求”后，插件找到的确实是平台原始录音容器（本次只读复核未解锁作答区）。
2. 平台开始/结束录音、计时更新、麦克风授权、回听和提交均未受固定定位影响。
3. 页面实际轮次数、红词文本和每轮静音秒数与助手显示一致。
4. 在一条普通轮和一条红词轮上完成全流程；红词计时不能被人工缩短。
5. 在实际使用的屏幕缩放比例与窗口尺寸下滚动到底，确认不遮挡剧本和平台控件。

若真实页面出现“无法识别剧本”或“录音控件未出现”，应停止依赖插件计时并记录页面截图；不能通过放宽选择器去猜测控件。
