# 英语录制节奏助手

一个运行在语录任务页中的悬浮计时扩展，用来辅助把握普通轮句末静音、红词后继续朗读 5 秒以及各轮切换节奏。

扩展会把原平台的真实录音区纵向挂在助手下方，使剧本较长、页面滚动或窗口较小时，计时提示和录音控件仍尽量保持在同一视口内。整个悬浮组合可以拖动、折叠和关闭。

> [!IMPORTANT]
> 这是非官方辅助工具，不替代项目录制规范、原平台录音、回听、上传或提交功能。正式提交前仍需按项目要求完整回听检查。

## 功能概览

- 自动读取可见剧本中的轮次与 `——Ns` 句末静音时长。
- 自动识别包含红色词语的轮次。
- 红词后固定继续朗读 5 秒，归零后自动进入该轮句末静音。
- 普通轮读完后，按剧本标注时长提示保持安静。
- 原平台录音区紧贴在助手下方，并随助手一起拖动。
- 支持鼠标主按钮和页面内全局快捷键 `F8`；不占用空格键。
- 关闭助手后，点击浏览器工具栏中的扩展图标可以恢复当前会话。
- 不申请麦克风权限，不读取、不保存、也不上传录音。

## 浏览器支持

| 浏览器 | 状态 | 扩展管理地址 | 说明 |
|---|---|---|---|
| Google Chrome 桌面版 | 已验证 | `chrome://extensions` | 推荐使用最新稳定版。 |
| Microsoft Edge 桌面版 | 已验证 | `edge://extensions` | 安装方式与 Chrome 基本一致。 |
| 联想浏览器桌面版 | 可安装，真实任务页待完整验收 | `slbrowser://extensions` | 语录任务页必须切换为“极速模式”；IE 模式不会运行 Chromium 扩展。 |
| 其他 Chromium 桌面浏览器 | 理论兼容，未逐一验证 | 以浏览器自身扩展管理页为准 | 必须支持 Manifest V3 和“加载已解压的扩展”。 |
| Internet Explorer、IE 模式 | 不支持 | — | 页面使用 IE 内核时，扩展内容脚本无法注入。 |
| Firefox、Safari | 不支持 | — | 当前版本没有提供对应格式。 |
| 手机和平板浏览器 | 不支持 | — | 本项目面向可加载桌面扩展的浏览器。 |

Chrome 是基于 Chromium 的浏览器产品；Edge 和联想浏览器的极速模式同样使用 Chromium 技术。这个扩展依赖 Chromium 的 Manifest V3 扩展机制，因此浏览器名称不同并不重要，页面当前使用的内核才是关键。

## 安装

### 第一步：下载并解压

1. 打开本仓库的 GitHub **Releases** 页面。
2. 在目标版本的 **Assets** 中下载 `english-recording-assistant.zip`。
3. 不要直接双击 ZIP，也不要选择 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`。
4. 将 ZIP 完整解压到一个不会被随手删除或移动的固定目录，例如：

   ```text
   D:\BrowserExtensions\english-recording-assistant
   ```

5. 打开解压后的目录，确认第一层可以直接看到 `manifest.json`。

浏览器加载的是这个解压目录，而不是复制一份扩展进去。因此安装后不要删除、重命名或移动该目录，否则扩展会失效。

如果“开发者模式”或“加载已解压”按钮不存在、不可点击，或者浏览器显示“由组织管理”，通常是单位策略禁止本地扩展。此时需要联系设备管理员，反复解压或刷新不能解决。

### Google Chrome

1. 在地址栏输入 `chrome://extensions` 并回车。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择第一层包含 `manifest.json` 的解压目录。
5. 打开语录任务页；如果任务页安装前已经打开，请刷新一次。
6. 可在拼图形“扩展程序”菜单中固定“英语录制节奏助手”，便于关闭后重新唤出。

Chrome 官方的本地扩展安装说明见 [Load an unpacked extension](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

### Microsoft Edge

1. 在地址栏输入 `edge://extensions` 并回车。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择第一层包含 `manifest.json` 的解压目录。
5. 打开或刷新语录任务页。
6. 如需固定图标，打开地址栏旁的“扩展”菜单并显示“英语录制节奏助手”。

Microsoft 官方的本地安装说明见 [Sideload an extension](https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/getting-started/extension-sideloading)。

### 联想浏览器

1. 在地址栏输入 `slbrowser://extensions` 并回车。
2. 打开“开发者模式”。
3. 点击“加载已解压的插件程序”。
4. 选择第一层包含 `manifest.json` 的解压目录。
5. 打开语录任务页。
6. 查看地址栏右侧的内核按钮：如果显示“正在使用 IE 模式”，点击它并选择“极速模式”。页面会重新加载。
7. 如任务页此前已经打开，再刷新一次。

扩展图标显示“可以访问此网站”，但助手仍完全不出现时，首先检查是否误用了 IE 模式。联想浏览器是双内核浏览器；安装成功不代表扩展能在 IE 内核页面中运行。

### 其他 Chromium 浏览器

不同浏览器的按钮名称可能略有差异，通常可按以下方式尝试：

1. 打开该浏览器的“扩展程序”或“插件”管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择第一层包含 `manifest.json` 的目录。
5. 刷新语录任务页。

如果浏览器不提供“加载已解压”或不支持 Manifest V3，则当前版本无法安装。未经实际验收的浏览器不建议直接用于正式录制。

## 使用说明

### 开始前

1. 正常登录语录平台并打开录制任务。
2. 确认地址以 `https://bytedance.aiforce.cloud/app/` 或 `https://bytedance.feishuapp.com/app/` 开头。
3. 等待剧本完整显示。助手应自动出现并显示轮次数、当前轮类型和句末静音时长。
4. 按平台要求确认题目，使真实的“用户录音”区域出现。
5. 确认助手状态显示“录音控件已悬浮”，并且原平台录音区位于助手正下方。
6. 点击原平台的录音按钮开始录音。助手不会代替你开始、暂停或结束录音。

### 录制节奏

| 场景 | 何时操作 | 操作后应该做什么 |
|---|---|---|
| 普通轮 | 完整读完本轮时 | 点击助手主按钮或按 `F8`，立即按倒计时保持安静。 |
| 红词轮 | 刚读完红色词语时 | 点击助手主按钮或按 `F8`，继续朗读；5 秒归零后立即停止朗读并保持安静。 |
| 红词后的 5 秒 | 不需要再次操作 | 继续按原文朗读。倒计时期间 `F8` 和重置操作都会被忽略或禁用。 |
| 句末静音 | 不需要操作 | 全程保持安静；归零后助手自动进入下一轮。 |
| 全部轮次完成 | 使用原平台控件 | 结束录音并回听，确认无误后再提交。 |

**红词轮不要等到整轮读完才按 `F8`；刚读完红词就应立即触发，然后继续朗读。**

每个红词后已至少预留 15 个英文词，正常语速足以覆盖 5 秒。红词后不要求把剩余文本全部读完；以助手 5 秒归零并进入“保持安静”为准。绿色词语不会触发助手操作。

当前助手只判断“一轮是否包含红色文字”，不会替用户在同一轮的多个红词之间选择触发点。如果真实剧本同一轮出现多个红词，应先按项目说明确认指定触发词，不要依靠助手猜测。

`F8` 是当前网页内的全局快捷键：即使焦点停留在平台按钮或输入框上，也能触发助手当前主操作。部分笔记本需要按 `Fn + F8`。扩展完全不接管空格键，因此空格仍保持页面原有行为。

### 面板操作

| 操作 | 作用 |
|---|---|
| 拖动标题栏 | 移动助手；原平台录音区会一起移动。位置保存在当前浏览器本地。 |
| 主按钮 / `F8` | 在允许操作的朗读阶段启动当前计时。 |
| “展开录音区 / 缩小录音区” | 调整原平台录音区在悬浮组合中的可见高度。 |
| `−` | 折叠或展开节奏面板。 |
| `×` | 关闭整个辅助悬浮组；原录音区回到平台原位置。 |
| 浏览器工具栏扩展图标 | 先激活原任务标签页，再点击图标，恢复被关闭的助手和当前计时会话。图标未固定时可从拼图形“扩展”菜单中找到。 |
| “重新扫描” | 页面加载异常或切题后，重新识别当前可见剧本。 |
| “重置” | 在没有运行倒计时时，回到本题第一轮。 |

关闭或折叠助手不会替你停止平台录音。计时运行时即使关闭助手，真实经过的时间仍会计入倒计时；重新打开后会显示正确阶段。

## 更新与卸载

### 更新本地扩展

1. 不要在录音过程中更新。
2. 下载新版本 ZIP。
3. 将新版本文件解压到原安装目录并替换旧文件；确保 `manifest.json` 仍位于该目录第一层。
4. 打开对应浏览器的扩展管理页，点击本扩展的“重新加载”。
5. 刷新语录任务页。

如果不想覆盖原目录，也可以移除旧扩展后从新目录重新安装，但面板位置、折叠状态等本地设置会重置。

### 卸载

1. 在浏览器扩展管理页找到“英语录制节奏助手”。
2. 点击“移除”或“删除”。
3. 确认不再需要旧版本后，再删除电脑上的解压目录。

## 权限与隐私

- 仅在以下两个精确站点范围运行：
  - `https://bytedance.aiforce.cloud/app/*`
  - `https://bytedance.feishuapp.com/app/*`
- 扩展 API 权限只申请 `storage`，用来保存面板位置、折叠状态、录音区大小和首次操作提示状态；浏览器所显示的“可访问此网站”来自上面的两个精确站点范围，并不代表可以访问其他网站。
- 不申请麦克风、浏览历史、下载、标签页历史或网络拦截权限。
- 不包含远程代码，不向外部服务器发起请求。
- 不读取、不保存、不处理、不上传录音内容。
- 原平台录音控件仍是原始 DOM 节点；扩展不会复制按钮或代替用户点击。

## 常见问题

### 安装时提示找不到清单文件

通常是选择了错误的目录层级。重新选择第一层直接包含 `manifest.json` 的目录，不要选择 ZIP 文件，也不要选择外面多包的一层文件夹。

### 扩展已安装，但助手没有出现

如果使用联想浏览器，先检查任务页地址栏是否显示“正在使用 IE 模式”；应切换为“极速模式”并等待页面重新加载。

其他情况依次检查：

1. 当前网址是否以 `https://bytedance.aiforce.cloud/app/` 或 `https://bytedance.feishuapp.com/app/` 开头。
2. 扩展是否已启用，并显示可以访问当前网站。
3. 安装或重新加载扩展后，任务页是否刷新过。
4. 是否曾点击 `×` 关闭助手；如果是，点击工具栏扩展图标恢复。

### 助手显示“录音控件未出现”

先按平台要求完成题目确认，使真实的“用户录音”区域显示。控件出现后插件会自动识别，也可以点击“重新扫描”。如果平台录音区已经清楚可见但仍无法识别，请不要依赖悬浮录音区，保留页面截图并反馈。

### 助手显示“无法识别剧本”

确认剧本已完整加载并且当前页面中能看到“轮次 N”和句末 `——Ns`，然后点击“重新扫描”。仍然失败时停止依赖插件计时；插件不会为缺失时长猜测默认值。

### `F8` 没有反应

- 确认当前处于“读完本轮后”或“读完红词后”的朗读阶段。
- 红词后 5 秒和句末静音期间，`F8` 本来就会被忽略，防止提前结束计时。
- 部分笔记本需要同时按 `Fn + F8`。
- 也可以始终使用助手主按钮。

### 红词处误按、漏按或计时已经错位

不要尝试在运行中的倒计时里连续按键或用“重置”拼接节奏。此时本次节奏已经不再可靠，应按原平台和项目规则结束本次录音并重录；重新开始前再使用“重置”回到第一轮。

### 更新后界面没有变化

仅替换文件不够。必须先在扩展管理页点击“重新加载”，再刷新任务页。Chrome 官方说明也要求内容脚本更新后同时重新加载扩展与宿主页。

### 面板挡住页面内容

拖动标题栏移开，使用 `−` 折叠，或点击 `×` 暂时关闭。需要时点击浏览器工具栏中的扩展图标恢复。

## 已知限制

- 语录平台如果修改剧本或录音区 DOM 结构，自动识别可能失效。
- 扩展只识别当前页面中可见的剧本，不处理图片、PDF 或手工粘贴的剧本。
- 当前版本只辅助节奏，不检查漏读、多读、发音、音量、底噪或录音质量。
- 当前版本只识别某一轮是否含红色文字，不处理同一轮多个红词的触发点选择。
- 本地加载的扩展不会像应用商店扩展一样自动更新，需要用户手动替换文件并重新加载。

## 开发与验证

项目要求 Node.js 20+、Python 3 和 Python Playwright。首次运行浏览器测试前安装 Chromium：

```powershell
python -m pip install playwright
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
python -m playwright install chromium
```

运行完整测试：

```powershell
npm test
npm run test:dom
npm run test:extension
npm run test:adversarial
```

生成 Release 安装包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-extension.ps1
```

产物位于 `dist/english-recording-assistant.zip`。压缩包根目录必须直接包含 `manifest.json`。

主要目录：

```text
extension/   浏览器扩展源码与图标
tests/       单元、DOM、扩展与对抗性测试
scripts/     图标生成与打包脚本
docs/        设计、架构决策、验收和发布文档
dist/        可上传到 GitHub Release 的安装包
```

更详细的发布步骤见 [发布指南](docs/RELEASING.md)，版本变化见 [CHANGELOG](CHANGELOG.md)，对抗性验证范围见 [验收记录](docs/adversarial-acceptance.md)。

## 使用提醒

在第一次正式录制前，建议用一条可重录任务完成全流程检查：剧本识别、录音区悬浮、拖动、普通轮静音、红词后 5 秒、结束录音、回听和提交。自动化测试不能替代登录后真实页面中的麦克风权限与提交验收。
