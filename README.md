# 英语录制节奏助手

这是一个仅用于语录平台的 Chrome / Edge 本地扩展。它让原平台的录音按钮和录音时长始终悬浮可见，并按剧本提示普通轮静音、红词后继续朗读 5 秒以及句末静音。

插件不录音、不上传数据，也不替代平台的提交逻辑。录音、权限、结束与回听仍由原平台完成。

## 安装

Chrome 和 Edge 的本地扩展不能直接双击 ZIP 安装，需要先解压：

1. 解压 `english-recording-assistant.zip`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的文件夹；该文件夹中应直接看到 `manifest.json`。

开发时也可以直接选择本仓库的 `extension` 文件夹。

## 使用

1. 从语录入口打开录制任务；登录后的任务页可能位于 `bytedance.feishuapp.com/app/...`。
2. 按平台提示点击“我已阅读并理解题目要求”，等待真实录音区出现。
3. 使用悬浮到页面底部的原平台按钮开始录音。
4. 普通轮读完：点击“开始静音”或按 `Space`。
5. 红词轮读到红词：点击“开始 5 秒”或按 `Space`，随后继续朗读。5 秒归零后插件自动进入该轮的静音倒计时。
6. 倒计时期间无需操作，`Space` 也不会提前结束计时。
7. 全部轮次完成后，使用原平台按钮结束录音并回听。

已确认每个红词后至少有 15 个词，正常语速足以朗读 5 秒，因此插件没有“提前静音”或文本长度判断。输入框、文本框、按钮等交互控件获得焦点时，插件不会抢占空格键。

计时运行时，“重新扫描”和“重置”会暂时停用，防止误触缩短当前倒计时；阶段结束后会自动恢复。

面板右上角的 `⇄` 可切换左右位置，`−` 可折叠。选择会保存在浏览器本地。

## 权限与隐私

- 只在语录入口 `https://bytedance.aiforce.cloud/app/*` 及其登录后任务域名 `https://bytedance.feishuapp.com/app/*` 运行。
- 只申请 `storage`，用于保存面板位置、折叠状态和首次提示状态。
- 不申请麦克风、浏览历史、网络拦截或其他网站权限。
- 没有外部网络请求和远程代码，不读取、保存或上传录音。

## 遇到问题

- “录音控件未出现”：先完成平台的题目确认步骤；录音区出现后插件会自动重新识别。
- “无法识别剧本”：不要依赖计时结果。确认页面已完整加载后点击“重新扫描”。
- 更新代码后界面没变化：在扩展管理页点击本扩展的“重新加载”，再刷新任务页。
- 空格没有触发：先让输入框或按钮等交互控件失焦；倒计时运行期间空格本来就会被忽略。
- 面板挡住内容：用 `⇄` 切换侧边，或用 `−` 折叠。

## 真实平台验收清单

首次正式录制前，请在登录后的真实任务页完成一次检查：

- [ ] 插件识别的轮次数和红词与页面一致。
- [ ] 解锁作答区后，原平台的按钮与录音时长悬浮在底部，点击仍能正常申请权限和录音。
- [ ] 滚动到长剧本底部时，助手与录音控件仍可见且不互相遮挡。
- [ ] 普通轮按剧本标注秒数静音。
- [ ] 红词后固定继续朗读 5 秒，期间无法用空格提前结束。
- [ ] 5 秒结束后自动进入该轮标注的静音。
- [ ] 原平台结束录音、回听和提交均正常。

更完整的对抗性检查记录见 `docs/adversarial-acceptance.md`。

## 开发验证

需要 Node.js 20+、Python 和 Playwright：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
python -m playwright install chromium
npm test
npm run test:dom
npm run test:extension
npm run test:adversarial
```

生成安装包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-extension.ps1
```
