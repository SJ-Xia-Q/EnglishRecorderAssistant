# 英语录制节奏助手

这是一个仅用于语录平台的 Chrome / Edge 本地扩展。它把原平台录音区纵向挂在节奏助手下方并随助手一起移动，同时按剧本提示普通轮静音、红词后继续朗读 5 秒以及句末静音。

插件不录音、不上传数据，也不替代平台的提交逻辑。录音、权限、结束与回听仍由原平台完成。

## 安装

Chrome 和 Edge 的本地扩展不能直接双击 ZIP 安装，需要先解压：

1. 解压 `english-recording-assistant.zip`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的文件夹；该文件夹中应直接看到 `manifest.json`。

开发时也可以直接选择本仓库的 `extension` 文件夹。

## 使用

1. 从语录入口打开录制任务；登录后的任务页可能位于 `bytedance.feishuapp.com/app/...`。
2. 按平台提示点击“我已阅读并理解题目要求”，等待真实录音区出现。
3. 使用助手下方的原平台录音区开始录音；需要查看更多录音内容时点击标题栏中的“展开录音区”。
4. 普通轮读完：点击“开始静音”或按 `F8`。
5. 红词轮读到红词：点击“开始 5 秒”或按 `F8`，随后继续朗读。5 秒归零后插件自动进入该轮的静音倒计时。
6. 倒计时期间无需操作，`F8` 也不会提前结束计时。
7. 全部轮次完成后，使用原平台按钮结束录音并回听。

已确认每个红词后至少有 15 个词，正常语速足以朗读 5 秒，因此插件没有“提前静音”或文本长度判断。`F8` 是页面内全局快捷键：焦点在平台按钮或输入框时仍可触发；插件完全不接管空格键。

计时运行时，“重新扫描”和“重置”会暂时停用，防止误触缩短当前倒计时；阶段结束后会自动恢复。

按住面板标题栏即可拖动，原平台录音区会始终紧贴在助手下方并一起移动，位置会保存在浏览器本地。窗口或可用高度变小时，整个纵向组合会自动上移，录音区缩短并在内部滚动，为页面底部操作区留出空间。标题栏中的 `▤/▥` 用于展开或缩小录音区，`−` 用于折叠节奏面板。点击 `×` 后助手消失、录音区回到平台原位置；点击浏览器工具栏中的扩展图标即可恢复同一会话，关闭期间正在运行的计时不会暂停或重置。

## 权限与隐私

- 只在语录入口 `https://bytedance.aiforce.cloud/app/*` 及其登录后任务域名 `https://bytedance.feishuapp.com/app/*` 运行。
- 只申请 `storage`，用于保存面板位置、折叠状态和首次提示状态。
- 不申请麦克风、浏览历史、网络拦截或其他网站权限。
- 没有外部网络请求和远程代码，不读取、保存或上传录音。

## 遇到问题

- “录音控件未出现”：先完成平台的题目确认步骤；插件可识别“待录制/点击开始录音”界面以及带计时的录制中界面。若真实录音区已经出现仍未识别，请截图反馈。
- “无法识别剧本”：不要依赖计时结果。确认页面已完整加载后点击“重新扫描”。
- 更新代码后界面没变化：在扩展管理页点击本扩展的“重新加载”，再刷新任务页。
- `F8` 没有触发：确认当前仍处于“读完本轮后/读完红词后”的朗读阶段；倒计时期间 `F8` 本来就会被忽略。部分笔记本需要同时按 `Fn+F8`。
- 面板挡住内容：拖动标题栏移开，或用 `−` 折叠；用 `×` 关闭后可点击扩展图标恢复。

## 真实平台验收清单

首次正式录制前，请在登录后的真实任务页完成一次检查：

- [ ] 插件识别的轮次数和红词与页面一致。
- [ ] 解锁作答区后，原平台录音区紧凑地排在助手正下方且同宽，点击仍能正常申请权限和录音。
- [ ] 拖动助手及切换录音区大小时，两者始终可见且不遮挡提交按钮。
- [ ] 普通轮按剧本标注秒数静音。
- [ ] 焦点位于平台按钮或输入框时 `F8` 仍可启动当前主操作，空格保持页面原生行为。
- [ ] 红词后固定继续朗读 5 秒，期间无法用 `F8` 提前结束。
- [ ] 5 秒结束后自动进入该轮标注的静音。
- [ ] 原平台结束录音、回听和提交均正常。

更完整的对抗性检查记录见 `docs/adversarial-acceptance.md`。

## 开发验证

需要 Node.js 20+、Python 和 Playwright：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.playwright-browsers"
python -m playwright install chromium
npm test
npm run test:dom
npm run test:extension
npm run test:adversarial
```

生成安装包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-extension.ps1
```
